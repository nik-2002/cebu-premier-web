# Real Supreme Real Estate Website Prototype

Static Next.js prototype for Real Supreme Real Estate. Content is stored in repo files for easy editing while the project is still pre-backend.

## Scripts

- `npm run dev` starts the local dev server.
- `npm run lint` checks code style.
- `npm run typecheck` runs TypeScript.
- `npm run build` creates the static export.
- `npm run preview:static` serves the generated `out/` folder with clean URLs.

## Content

- Listings: `src/data/listings.ts`
- Agents: `src/data/agents.ts`
- Projects: `src/data/projects.ts`
- Site and contact copy: `src/data/site.ts`
- Brand tokens: `src/data/brand.ts` and `src/styles/brand.css`
- Future Canva/logo/photo assets: `public/assets/brand/`
